## 题目（当场写死口径）

n 名奔跑者在周长 1 的圆上，速率两两不同（可含负）。t=0 时同点出发。称某人在时刻 t **孤独**，若沿圆量到其余每个人的距离都 ≥ 1/n。

**猜想**：对任意这样的速率组，每个人都存在某个时刻孤独。

等价常用形（Wills）：把要检查的那个人速率减成 0，剩下 n−1 个正的互异速率 v₁,…,v_{n−1}，存在 t>0 使对每个 i：

    1/n ≤ {vᵢ t} ≤ 1 − 1/n

其中 {·} 是小数部分。本攻坚默认用这个口径。一旦改口径必须当场定义（「n 人」vs「n−1 个运动者」不要混）。

view-obstruction / 距离图染色是推论方向，不是本轮必须做的。
