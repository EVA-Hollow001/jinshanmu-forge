# Collatz 路线A（素因子覆盖）第1轮铺路报告

记号：非平凡环取全体奇数元素 n_1,…,n_m（n_{i+1}=(3n_i+1)/2^{a_i}，下标 mod m），
a_i = v₂(3n_i+1) ≥ 1，A = Σ_{i=1}^m a_i，n_1 取为最小元素。
所有引理状态标注 [继承]/[本轮新推]/[本轮修正]/[待验证]。

---

## 0. 对继承战果的一处必须修正

[继承] 记为「n₁(2^A−3^m)=−N，2^A<3^m」。这与环的定义矛盾，必须纠正：

对环方程 n_{i+1}=(3n_i+1)/2^{a_i} 逐项连乘：

2^{a_i}·n_{i+1} = 3n_i+1
⟹ Π_i (2^{a_i} n_{i+1}) = Π_i (3n_i+1)
⟹ 2^A Π_i n_{i+1} = Π_i (3n_i+1)
⟹ 2^A Π_i n_i = Π_i (3n_i+1)          （Π n_{i+1}=Π n_i，环）
⟹ 2^A = Π_i (3n_i+1)/n_i = Π_i (3 + 1/n_i) > 3^m     （每个因子 >3）

因此 **[本轮修正]：2^A > 3^m（即 A > m·log₂3），且 Böhm–Sontacchi 为 n₁(2^A − 3^m) = N（正号，非 −N）**。

平凡环验证（m=1，n₁=1，a₁=2，A=2）：
2^A − 3^m = 4 − 3 = 1 = N（N=Σ 3^{0}2^{s_0}=1，见 L8），n₁(2^A−3^m)=1·1=1=+N ✓，
且 2^A=4>3=3^m ✓。故「2^A<3^m / 负号」不成立，本报告一律用修正后的正号版本。

## 1. 引理链

### L1（a）环元素不被 3 整除　[本轮新推]
**陈述**：任意 Collatz 环（含平凡环）满足 3 ∤ n_i，∀i。

**证明**：由 n_i = (3n_{i−1}+1)/2^{a_{i−1}}（下标 mod m）得
n_i · 2^{a_{i−1}} = 3n_{i−1} + 1 ≡ 1 (mod 3)。
若 3|n_i，则左端 ≡ 0 (mod 3)，与 ≡1 矛盾。∎

（这是「覆盖」论证能给出的第一个硬约束：环上任何元素 mod 3 只能是 ±1。）

### L2（b）相邻元素互素　[本轮新推]
**陈述**：gcd(n_i, n_{i+1}) = 1，∀i。

**证明**：设 d | n_i 且 d | n_{i+1}。因 n_i 为奇，d 奇；又
n_{i+1} = (3n_i+1)/2^{a_i} ⟹ 2^{a_i} n_{i+1} = 3n_i+1，
故 d | (3n_i+1)。于是 d | (3n_i+1) − 3n_i = 1，d=1。∎

### L3（b′，推广）隔 k 步的公因子整除一个奇系数　[本轮新推]
**陈述**：∀i, ∀k≥1，
2^{A_{i,k}} n_{i+k} = 3^k n_i + N_k，
其中 A_{i,k} := a_i+⋯+a_{i+k−1}，N_k := Σ_{r=0}^{k−1} 3^{k−1−r} 2^{s_r}，
s_0=0，s_r := a_i+⋯+a_{i+r−1}（r≥1）。
故 gcd(n_i, n_{i+k}) | N_k，且 N_k 为奇数、N_k ≢ 0 (mod 3)。

**证明**：对 k 归纳（迭代 n_{i+t+1}=(3n_{i+t}+1)/2^{a_{i+t}}）直接得到上述线性式；
k=1 即 L2（N_1=1）。奇性：N_k 各项中仅 r=0 项 3^{k−1}·2^{s_0}=3^{k−1} 为奇，其余含因子 2^{s_r}（s_r≥1）为偶，故 N_k 奇。
mod 3：N_k ≡ 2^{s_{k−1}} ≡ (−1)^{s_{k−1}} ≢ 0 (mod 3)。∎

### L4（mod 3 残差决定律）　[本轮新推]
**陈述**：n_i ≡ (−1)^{a_{i−1}} (mod 3)，∀i。

**证明**：n_i·2^{a_{i−1}} = 3n_{i−1}+1 ≡ 1 (mod 3)，且 2^{a_{i−1}} ≡ (−1)^{a_{i−1}}，
故 n_i ≡ 2^{−a_{i−1}} ≡ 2^{a_{i−1}} ≡ (−1)^{a_{i−1}} (mod 3)。∎

**推论（自洽性核对）**：该律与 L8 的 B–S 自动相容，不给新约束。
证：n₁ ≡ (−1)^{a_m}；又 N ≡ 2^{s_{m−1}} ≡ (−1)^{s_{m−1}} = (−1)^{A−a_m}；
2^A−3^m ≡ (−1)^A (mod 3)。于是
n₁(2^A−3^m) ≡ (−1)^{a_m}(−1)^A = (−1)^{A+a_m} = (−1)^{A−a_m} ≡ N (mod 3) ✓
（A+a_m 与 A−a_m 差 2a_m，偶）。恒成立，无信息量。

### L5（端点指数约束）　[本轮新推]
**陈述**：非平凡环中 a_1 = 1，a_m ≥ 2。

**证明**：
- n₂ = (3n₁+1)/2^{a_1} ≥ n₁（n₁ 最小）。若 a_1 ≥ 3，则 2^{a_1} ≥ 8 > 3+1/n₁，
  得 n₂ < n₁，矛盾。若 a_1 = 2，则 n₂ ≥ n₁ ⟺ 3n₁+1 ≥ 4n₁ ⟺ n₁ ≤ 1 ⟹ n₁=1，
  即平凡环。故非平凡环 a_1=1。
- 前驱 n_m = (n₁·2^{a_m} − 1)/3 ≥ n₁ ⟹ n₁(2^{a_m}−3) ≥ 1 > 0 ⟹ 2^{a_m} > 3 ⟹ a_m ≥ 2。∎

**推论**：非平凡环 A ≥ m+1（因 a_1=1, a_m≥2, 其余 a_i≥1）。

### L6（A 的双侧界）　[本轮新推]
**陈述**：⌊m·log₂3⌋ + 1 ≤ A ≤ 2m − 1。

**证明**：
下界：2^A > 3^m（L0）⟹ A > m log₂3 ⟹ A ≥ ⌊m log₂3⌋+1。
上界：每个因子 3+1/n_i < 4（n_i ≥ 1）⟹ 2^A = Π(3+1/n_i) < 4^m = 2^{2m} ⟹ A < 2m。∎

### L7（n₁ 的双侧界）　[本轮新推]
**陈述**：令 δ := 2^A/3^m − 1 > 0，则
1/(3δ) ≤ n₁ ≤ (1+δ)(3/2)^m / δ，　且 n₁ ≤ 1/(2^{A/m} − 3)。

**证明**：
(上界一) 因 n_i ≥ n₁，有 3+1/n_i ≤ 3+1/n₁，故
2^A = Π(3+1/n_i) ≤ (3+1/n₁)^m ⟹ 2^{A/m} ≤ 3+1/n₁ ⟹ n₁ ≤ 1/(2^{A/m}−3)。（分母>0，由 2^A>3^m）

(下界) N = Σ_{i=0}^{m−1} 3^{m−1−i} 2^{s_i} ≥ 3^{m−1}·2^{s_0} = 3^{m−1}（其余项非负），
故 n₁ = N/(2^A−3^m) ≥ 3^{m−1}/(δ·3^m) = 1/(3δ)。

(上界二) s_i ≤ A − (m−i)（剩下 m−i 个指数各 ≥1），故
N ≤ Σ_{i=0}^{m−1} 3^{m−1−i} 2^{A−m+i} = 2^{A−m} Σ_{i=0}^{m−1} 3^{m−1−i}2^i = 2^{A−m}(3^m−2^m)，
n₁ = N/(2^A−3^m) ≤ 2^{A−m}(3^m−2^m)/(δ·3^m) = (1+δ)(3^m−2^m)/(δ·2^m) < (1+δ)(3/2)^m/δ。∎

**诚实注**：区间 [1/(3δ), (1+δ)(3/2)^m/δ] 对所有合法 (m,A) 都非空且总含奇数，
故 L7 是**界**而非**排除条件**（见 §3 卡点）。

### L8（修正后的 Böhm–Sontacchi）　[本轮修正]
**陈述**：环 ⟺ 存在 a_1,…,a_m ≥ 1 使
n₁(2^A − 3^m) = N，　N := Σ_{i=0}^{m−1} 3^{m−1−i} 2^{s_i}，
s_0=0，s_i=a_1+⋯+a_i（i≥1），且 n₁=N/(2^A−3^m) 为奇正整数、逐点
n_{i+1}=(3n_i+1)/2^{a_i} 严格闭合（2^{a_i} || 3n_i+1）。

**证明**：迭代 m 步得 n_{m+1} = (3^m n₁ + N)/2^A；闭合 n_{m+1}=n₁ ⟺ n₁(2^A−3^m)=N。
（方向、符号均与 L0 一致。）∎

### L9（覆盖骨架是同义反复；责任链退化）　[本轮新推]
**陈述**：
(1) 覆盖方程 2^A Π n_i = Π(3n_i+1) 与环方程之积等价，不含环之外的独立信息。
(2) 责任链：对固定奇素数 p，令 S_p = {i : p | n_i}，则
　　p | n_i ⟺ p | 3n_{i−1}+1 ⟺ n_{i−1} ≡ −3^{−1} (mod p)（i−1 为 i 的直接前驱）。
　　「n_i 的每个奇素因子必须整除某 (3n_j+1)（j≠i）」恒由 j=i−1 满足；
　　责任映射 i ↦ i−1 就是向后平移，是一个长度 m 的指标环，不给任何指标间新关系。
(3) 无法把链推进成矛盾：要由 n_{i−1} ≡ −3^{−1} 继续推到 n_{i−2} mod p，需要
　　3n_{i−2} ≡ n_{i−1}·2^{a_{i−2}} − 1 (mod p)，右端依赖 a_{i−2}（模 p 动力学非自治），
　　故得不到 n_{i−2} 的确定残差，链无法闭合成两个 n_k 的同余冲突。

**证明**：(1) 见 L0 推导，等式恰为逐项连乘。(2) p 奇，p | n_i ⟺ p | (3n_{i−1}+1)/2^{a_{i−1}} ⟺ p | 3n_{i−1}+1。
(3) 直接代入环递推。∎

## 2. 主结论（本轮最强可证结论）

**定理（路线A·第1轮）**：设 n_1<…（n₁=min）为任意 Collatz 环（允许平凡），m≥1，A=Σa_i，δ=2^A/3^m−1，则：

(i)  3 ∤ n_i，∀i；　n_i ≡ (−1)^{a_{i−1}} (mod 3)，∀i；
(ii) gcd(n_i,n_{i+1})=1；　gcd(n_i,n_{i+k}) | N_k（N_k 奇、≢0 mod 3）；
(iii) 非平凡时 a_1=1、a_m≥2；　⌊m log₂3⌋+1 ≤ A ≤ 2m−1；
(iv) 1/(3δ) ≤ n₁ ≤ (1+δ)(3/2)^m/δ，且 n₁ ≤ 1/(2^{A/m}−3)；
(v)  n₁(2^A−3^m) = Σ_{i=0}^{m−1} 3^{m−1−i} 2^{s_i}（修正后 B–S，正号；2^A>3^m）。

**就路线A自身的目标而言的结论**：素因子覆盖骨架与环方程同义（L9），**不产生独立约束**；本路线能独立得到的全部新结果就是 (i)–(iv) 这些必要条件。它们都不排除非平凡环。路线A若要继续，唯一有判别力的是 (v) 的 B–S 同余（继承归约，修正符号后），见 §3、§5。

## 3. 卡点（精确）

**卡点1（责任链的非自治性）**：模 p 的动力学 n_{i} ≡ (3n_{i−1}+1)2^{−a_{i−1}} (mod p)
依赖半减指数 a_{i−1}，它不是 mod p 的函数。因此「p|n_i ⟹ p|3n_{i−1}+1 ⟹ n_{i−1}≡−1/3」
无法再往前推一步而不引入 a_{i−2} 的自由度；责任链不能闭合成两个元素同余冲突。
**这是本轮无法由覆盖论证导出矛盾的精确技术点。**

**卡点2（覆盖=同义反复）**：覆盖方程是环方程之积（L9(1)），信息量等于环方程之和，无新增。

**卡点3（B–S 搜索空间指数级）**：修正后 B–S 的判别等价于在
「0=s_0<s_1<⋯<s_{m−1}<A」的 C(A−1,m−1) 个组合上判定 N≡0 (mod 2^A−3^m)。
对 A=ρm，log₂ C(A−1,m−1) ≈ ρ m · H(1/ρ)（H 为二元熵），
ρ∈[1.585,2] 时 ≈ [1.50m, 2m] 比特。m=10^5 ⟹ 2^{1.5×10^5} 量级，蛮力不可行。
**若需突破，要的已知定理是**：Simons–de Weger 型的连分数+格归约（LLL）方法（把可行
(m,A) 压缩到 log₂3 的连分数收敛子附近、并用格解 B–S 同余）。其确切复杂界我**不能给出**，标 [待验证]；
本报告不把该已知方法冒充为本轮新发现。

**注**：由 [继承] 的现代下界 m ≳ 10^10，m≤10^5 的环已被已知结果排除；§5 的算法是按路线要求、
用覆盖/B–S 口径写的「可判定排除」版本，不宣称新的排除。

## 5. （d）覆盖/B–S 口径的「m≤10^5 可判定排除」算法与真实复杂度

### 伪代码

```
DECIDE_CYCLE(M):                       # 判定是否存在 ≤M 个奇元素的非平凡环
  for m = 2 .. M:
    Amax = 2*m - 1
    Amin = floor(m*log2(3)) + 1
    for A = Amin .. Amax:              # L6 界
      D = 2^A - 3^m                    # >0, A 比特大整数
      delta = 2^A/3^m - 1              # 高精度有理/浮点，仅用于界
      # --- 廉价必要条件（O(1)，见 L7；注意它们是界、非排除） ---
      lo = 1/(3*delta)
      hi = (1+delta)*(3/2)^m / delta
      if not exists odd integer in [lo, hi]: continue    # 实际恒成立，见注
      if a_1!=1 or a_m<2 结构性检查: continue            # 嵌入搜索时用
      # --- 决定性步骤：B–S 同余 ---
      # 是否存在 0=s_0<s_1<...<s_{m-1}<A 使
      #   sum_{i=0}^{m-1} 3^{m-1-i} * 2^{s_i} ≡ 0 (mod D) ？
      if BS_SOLVABLE(m, A, D):
          n1 = N/D                     # N 为该组合的和
          if 验证 orbit 闭合且 2^{a_i} || 3n_i+1 对 i=1..m:  RETURN (n1, a[1..m])
  return NONE

BS_SOLVABLE(m, A, D):                  # 两种实现，复杂度如实
  1) 朴素枚举：枚举 C(A-1, m-1) 个严格递增 (s_1..s_{m-1})，逐一对 N mod D 求值。
     复杂度 C(A-1,m-1)·O(m) 次大整数运算。
  2) DP：状态 (j, s) = 已选 s_1..s_j 且 s_j=s 时可达到的 N 部分和模 D 的残差集 R(j,s)。
     转移 (j,s) → (j+1,s'), s'>s，加 3^{m-j-1}·2^{s'} (mod D)。
     复杂度 O(m·A·R_max)，R_max = max|R(j,s)|（残差集大小，最坏指数，无已知多项式界 [待验证]）。
```

### 真实参数与复杂度（m≤10^5）

- log₂3 = 1.584962500721156…；
- 每 m 的 A 取值数 = 2m − ⌊m log₂3⌋ − 1 ≈ 0.4150375 m；
- 总 (m,A) 对数 ≈ (2−log₂3)·(10^5·(10^5+1)/2) ≈ **2.0752 × 10^9 对**；
- 每对的 D = 2^A − 3^m 位长 ≈ A ≤ 2×10^5 比特（约 25 KB），大整数运算 O(A) 字。
- 每对的组合空间：A=ρm 时 log₂ C(A−1,m−1) ≈ ρ m H(1/ρ)。
  ρ=1.585（H(0.631)≈0.9486）：≈ 1.5037m ≈ 1.5×10^5 比特（m=10^5）；
  ρ=2（H(0.5)=1）：≈ 2m ≈ 2×10^5 比特。
  即朴素 BS_SOLVABLE 为 2^{Θ(m)}，**对 m=10^5 完全不可行**。
- DP 版最坏 O(m·A·R_max)，R_max 无多项式界（诚实标注 [待验证]）。

**结论**：把覆盖约束翻译成的数值必要条件（L1–L7）都是多项式可检的（2×10^9 个 (m,A) 对 × O(1)），
但都不排除；唯一有判别力的 B–S 同余判定对 m=10^5 在朴素口径下是 2^{Θ(m)}。因此本路线第 1 轮
**不能**给出 m≤10^5 的有效排除；有效的排除要么引用 [继承] 的已知下界 m≳10^10，要么需要
[待验证] 的连分数+格归约方法。
