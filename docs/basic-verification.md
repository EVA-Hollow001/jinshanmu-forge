**成立条件**：m 为**偶数**时 v₂(3^m−1) = v₂(m)+2 精确成立（m=2,4,…,30 全 15 个偶数全通过）；m 为**奇数**时 v₂(3^m−1)=1 而 v₂(m)+2=2，差 1（15 个奇数全部不成立）。

## 第 6 项 n₁ 界方向自检 — 通过（正数域恒真；负数域被破坏，需警惕）

200 组随机样本（m∈[2,30]，n₁∈[1,1000]，nᵢ≥n₁ 混合分布）：
- **不等式 Π(3+1/nᵢ) ≤ (3+1/n₁)^m 违反次数 = 0**（应恒真 ✅，因为 nᵢ≥n₁>0 ⟹ 1/nᵢ≤1/n₁）
- 比值 R = LHS/RHS ∈ **[0.129586, 0.999957]**，全部 ≤ 1
- **反向误写（声称 LHS≥RHS）**：最大错误发生在 min R≈0.1296，即真实 LHS 比 RHS 小约 **7.72 倍**
- **等号误写（声称 LHS=RHS）**：最大相对偏差 |R−1| ≈ **0.870**（约 87%）

**重要警告**：该不等式只对正 n₁ 成立。对**负循环**（n₁<0）单调性反转，直接破坏：
- −5 循环（n₁=−5）：R = 8.000/7.840 = **1.0204 > 1** ✗
- −17 循环（n₁=−17）：R = 2048.000/1903.915 = **1.0757 > 1** ✗

即：若攻击证明把此界用于负循环参数，方向会反，量级约 2–8%。

## 总评：可用于后续攻击阶段的「可信公共事实」

1. **log₂3 = 1.58496250072115618145…**，连分数 `[1;1,1,2,2,3,1,5,2,23,2,2,1,1,55,…]`（可信）。**下逼近（q·α−p>0）恰为偶数下标收敛子**：k=0,2,4,6,8,10,12,14。⚠️ 引用收敛子时务必用 24727/15601（k=9）与 16785921/10590737（k=14），a₁₄=55——不要沿用 15597/5 的记忆值。
2. **负循环参数**：−5 循环 (m=2, A=3, A/m=1.5)；−17 循环 (m=7, A=11, A/m=11/7≈1.57143)。两者恒等式 2^A·Πnᵢ=Π(3nᵢ+1) 整数精确成立，A/m 均 < log₂3。
3. **LTE 成立范围**：v₂(3^m−1)=v₂(m)+2 **仅 m 偶时成立**；m 奇时 v₂(3^m−1)=1。凡涉及 v₂(3^m−1) 的证明必须分 m 奇偶，否则 −1 系统误差。
4. **D=3^m−2^A 候选表（40 组）全部完全分解、无 >10⁶ 大因子**；唯一 D=1 在 (m,A)=(2,3)。该区间（m<A<m·log₂3）正是**负循环参数区**（闭合方程 n₁(3^m−2^A)=−N，D>0 需整除 N）。
5. **不等式 Π(3+1/nᵢ)≤(3+1/n₁)^m 仅对正 n 恒真**（200 组 0 违反；反向/等号误写最大偏差 ~7.7 倍/~87%）。**负循环会破坏它**（R>1），绝不可把正 n 界搬到负循环。
6. **Böhm–Sontacchi 前缀方程（非闭合）对任意轨道精确成立**，可作恒等式库；**闭合式只对真循环成立**，27 链（A/m=5/3>log₂3）不可套用。
