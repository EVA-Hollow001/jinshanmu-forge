- 正循环：\(2^A=\prod(3+1/n_i)>3^m\)，即 \(A/m>\log_2 3\)（从上侧逼近）。负循环 \(A/m<\log_2 3\)。

- \(\log_2 3=[1;1,1,2,2,3,1,5,2,23,2,2,1,1,55,\ldots]\)。k=9 收敛子 **24727/15601**（不是 15597）。偶下标下逼近，奇下标上逼近。
- LTE：\(v_2(3^m-1)=v_2(m)+2\) **仅 m 偶**；m 奇时 \(=1\)。
- \(n_1\le 1/(2^{A/m}-3)\) 与 \(\prod(3+1/n_i)\le(3+1/n_1)^m\) **仅正侧**。负侧方向反转。

- 窗（\(n_1\ge 5\)）：\(A/m\in(\log_2 3,\log_2 3.2]\)，宽度 \(\log_2(16/15)\approx 0.09311\)。

## 2. 每条死路卡在哪个技术点（精确）

1. **覆盖 / 责任链**：乘积恒等式不产生独立同余；模 p 动力学依赖 \(a_i\)，非自治。
2. **3-adic**：\(2^A-3^m\) 是 3-adic 单位，\(n_1\) 对任意 \((a_i)\) 良定义。
3. **S-unit / Baker**：两变量线性对数给不出主项；压 \(n_1<5\) 要指数 \(f\)；真实 \(f\) 不够。
4. **A 唯一 / 小 d**：不等式方向用错（\(N_{\min}\) vs \(N_{\max}\)）。
5. **窗内夹逼**：合法界自动成立；\(I\) 恒非空（至少 \(m\le 200\) 穷尽 + 解析端点）。
6. **组合枚举**：叶数天文。
7. **T-扫描**：\(N_{\max}\) 在上逼近层爆炸；3 天可做一层，两年不可做。
8. **小 D 穷尽**：\(D\le 10^9\) 已清；更大 D 组合爆炸，需新算法。
9. **\(\varphi(m)\) / m-循环约化**：本攻坚**未真正打开**。这是文献把 Baker 变成有限核验的通道。要闭合需要：精确陈述 + 可核验常数 + 本轮 E4（恰周期）对接。**这是下一轮若还打 Collatz 的唯一理论活口。**
