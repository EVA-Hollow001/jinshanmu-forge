# Collatz 路线B 第1轮：S-unit 方程 n₁(2^A−3^m)=N 的显式求解与排除

标签约定：`[继承]` 直接使用已有战果；`[本轮新推]` 本轮独立推出；`[待验证]` 不确定/需外部核验。

## 0. 总方程与符号（重验，非照抄）

加速映射 T(n)=(3n+1)/2^{v₂(3n+1)}。设正环为奇数序列 n₁,…,n_m（m 个奇数，n_{m+1}=n₁），
aᵢ=v₂(3nᵢ+1)，s₀=0，sᵢ=a₁+⋯+aᵢ，A=s_m。

递推 n_{i+1}=(3nᵢ+1)/2^{aᵢ} 展开 m 步：

n_{i+1} = (3^i n₁ + Σ_{j=1}^{i} 3^{i−j} 2^{s_{j−1}}) / 2^{s_i}.

取 i=m、n_{m+1}=n₁，得

**n₁(2^A − 3^m) = N，  N = Σ_{i=1}^{m} 3^{m−i} 2^{s_{i−1}}。**

平凡环 m=1,A=2,a₁=2：N=1，1·(4−3)=1 ✓（此后所有引理都过这个校验点）。

N>0 且 n₁>0 ⟹ **2^A>3^m**（正环只在 2^A>3^m 侧，与[已核验]一致）。

## 1. 引理链

### L1 [本轮新推 · 符号订正] 3-adic 同余：n₁ ≡ N·2^{−A} (mod 3^m)

**证明**：n₁(2^A−3^m)=N。模 3^m，2^A−3^m ≡ 2^A，故 n₁·2^A ≡ N (mod 3^m)，即

n₁ ≡ N·2^{−A} (mod 3^m)。   （2 是模 3^m 的单位）

**订正**：任务书所写「n₁ ≡ −N·2^{−A}」符号有误。平凡环检验：m=1,A=2,N=1，
N·2^{−2}≡1≡n₁ (mod 3) ✓；而 −N·2^{−2}≡−1≡2≢1 ✗。即使改写成 n₁(3^m−2^A)=−N，
模 3^m 得 n₁(−2^A)≡−N ⟹ n₁·2^A≡N，仍回到 +N。**正确同余为 +N·2^{−A}。**

**一致性（附）**：N mod 3 只有 i=m 项存活，N≡2^{A−a_m} (mod 3)，故
n₁≡N·2^{−A}≡(−1)^{a_m} (mod 3)，恰为 mod3 决定律在 i=1 处（n₁=T(n_m)）的形式。同余自洽。

### L2 [继承 · 重验] 递推展开与 s 的严格递增

n_{i+1}=(3nᵢ+1)/2^{aᵢ}，aᵢ≥1 ⟹ s 严格递增，sᵢ−s_{i−1}=aᵢ。展开式同 §0。Böhm–Sontacchi 即 L2 在 i=m 的特例。**3∤nᵢ、gcd 邻项=1、a₁=1、a_m≥2、⌊m·log₂3⌋+1≤A≤2m−1** 均[继承]。

### L3 [本轮新推] N 的双边估计

**证明**：
- 下界：i=1 项 = 3^{m−1}·2^{s₀}=3^{m−1}，其余项全正 ⟹ **N ≥ 3^{m−1}**。
- 上界：s 递增故 2^{s_{i−1}} ≤ 2^{s_{m−1}} = 2^{A−a_m}，逐项
  3^{m−i}2^{s_{i−1}} ≤ 3^{m−i}2^{A−a_m}，求和
  N ≤ 2^{A−a_m}·Σ_{i=1}^{m}3^{m−i} = 2^{A−a_m}(3^m−1)/2。
  用 a_m≥2 ⟹ 2^{A−a_m}≤2^{A−2}，且 3^m−1<3^m：
  **N < 3^m·2^{A−2}/2**。

逐项方向自检：每处都是「大项≥小项」的正向放缩，无减号，无符号翻转。

### L4 [本轮新推] n₁ 的双边估计

**证明**：n₁=N/(2^A−3^m)，2^A−3^m 为正整数（≥1）。
- 下界：n₁ ≥ 3^{m−1}/(2^A−3^m)（L3 下界）。
- 上界：n₁ ≤ N（因 2^A−3^m≥1）< 3^m·2^{A−2}/2 = **3^m·2^{A−3}**。
  即 **0 < n₁ < 3^m·2^{A−3}**。

平凡环：下界 1/1=1≤1；上界 3·2^{−1}=1.5>1 ✓。

### L5 [本轮新推] 3-adic 刚性：2^A>(8/7)·3^m ⟹ n₁ 被奇偶向量唯一决定

**证明**：由 L3 上界，n₁ ≤ 2^{A−a_m}(3^m−1)/(2(2^A−3^m)) < 2^{A−a_m}·3^m/(2(2^A−3^m))。
要使 n₁<3^m，只需 2^{A−a_m} ≤ 2(2^A−3^m)，即 3^m ≤ 2^A(1−2^{−a_m−1})。
a_m≥2 ⟹ 1−2^{−a_m−1} ≥ 7/8。故 **2^A > (8/7)·3^m ⟹ n₁<3^m**。

于是 L1 的最小正剩余**精确等于 n₁**：n₁ = (N·2^{−A} mod 3^m)，无自由参数。

**推论 L5′（硬区窗口）**：令 δ=A−m·log₂3。2^A>(8/7)3^m ⟺ δ>log₂(8/7)=0.192645…。
故非刚性区为 0<δ≤0.192645，即 A∈(m log₂3, m log₂3+0.192645]。
该区间长 0.192645<1，**对每个 m 至多含一个整数 A**。
结论：对每个 m，除至多一个（最贴近 m log₂3 的）A 外，其余全部 A 落入刚性区（n₁<3^m、被向量唯一决定）。

### L6 [本轮新推] 真正的 2-adic 杠杆：不是 v₂(2^A−3^m)，而是模 2^A 可逆

**证明**：A≥1 ⟹ 2^A 偶、3^m 奇 ⟹ 2^A−3^m 为**奇**，v₂(2^A−3^m)=0。
因此 2^A−3^m 是模 2^A 的单位，由 L1 同款手法模 2^A：

n₁ ≡ N·(2^A−3^m)^{−1} (mod 2^A)，

其中 N mod 2^A=Σ_{i=1}^{m}3^{m−i}2^{s_{i−1}}（因 s_{i−1}≤A−a_m<A，无项消没）。
**奇偶向量 (a₁,…,a_m) 唯一决定 n₁ mod 2^A。**

### L7 [本轮新推] 模 4 双向等价：aᵢ 与 nᵢ mod 4

3^{−1}≡3 (mod 4)。
- nᵢ≡1 (mod 4)：3nᵢ+1≡3·1+1=4≡0 ⟹ v₂≥2，**aᵢ≥2**。
- nᵢ≡3 (mod 4)：3nᵢ+1≡3·3+1=10≡2 ⟹ v₂=1，**aᵢ=1**。
反向：aᵢ≥2 ⟹ 3nᵢ+1≡0 (mod 4) ⟹ 3nᵢ≡3 ⟹ nᵢ≡1 (mod 4)；aᵢ=1 ⟹ nᵢ≡3 (mod 4)。
**双向成立**：nᵢ≡1(mod4) ⟺ aᵢ≥2；nᵢ≡3(mod4) ⟺ aᵢ=1。

### L8 [继承+本轮新推] mod3 决定律与 mod12 联合表

mod3 决定律[继承]：nᵢ=(3n_{i−1}+1)/2^{a_{i−1}} ≡ 1·2^{−a_{i−1}} ≡ (−1)^{a_{i−1}} (mod 3)。

与 L7 合 CRT（gcd(3,4)=1）得 nᵢ mod 12：

| a_{i−1} 奇偶 | aᵢ | nᵢ mod 12 | 含义 |
|---|---|---|---|
| 偶 (nᵢ≡1 mod3) | ≥2 (nᵢ≡1 mod4) | 1 | 下一指数≥2 |
| 偶 | =1 (nᵢ≡3 mod4) | 7 | 下一指数=1 |
| 奇 (nᵢ≡2 mod3) | ≥2 | 5 | 下一指数≥2 |
| 奇 | =1 | 11 | 下一指数=1 |

验证：1≡1,1；7≡1,3；5≡2,1；11≡2,3（前 mod3，后 mod4）✓。

### L9 [本轮新推] 模 3·2^{aᵢ+1} 联合约束

v₂(3nᵢ+1)=aᵢ ⟺ 3nᵢ+1≡2^{aᵢ} (mod 2^{aᵢ+1}) ⟺ **3nᵢ≡2^{aᵢ}−1 (mod 2^{aᵢ+1})**。
与 nᵢ≡(−1)^{a_{i−1}} (mod 3) 联立（gcd(3,2^{aᵢ+1})=1）：
**nᵢ 在模 3·2^{aᵢ+1} 下被 (a_{i−1},aᵢ) 唯一确定**。该模随 aᵢ 增长——见卡点3。

### L10 [本轮新推] 完全等价（结构性还原）

**命题**：正 Collatz 环与满足以下三条件的 (m; a₁,…,a_m) 一一对应：
- (E1) 2^A>3^m；
- (E2) n₁:=N/(2^A−3^m) ∈ Z⁺；
- (E3) 对每个 i=1..m，递归定义的 nᵢ 满足 3nᵢ+1≡2^{aᵢ} (mod 2^{aᵢ+1})（即 aᵢ=v₂(3nᵢ+1) 精确）。

**证明**：
- 必要性：环的定义即 (E1)(E2)(E3)（E2 为 BS 方程，E3 为 aᵢ 定义）。
- 充分性：E2 ⟹ n₁>0 奇（N 奇、2^A−3^m 奇，商为奇）；E3(i=1) ⟹ 2^{a₁}|3n₁+1 ⟹ n₂∈Z 且奇；
  归纳得 nᵢ 全为正奇数；E3(i=m)+E2 得 n_{m+1}=n₁。闭环。∎

**注**：N 为奇数（i=1 项奇，其余项被 2 整除），2^A−3^m 奇，故 E2 成立的 n₁ 自动为奇。

### L11 [本轮新推] 指数=1 的计数下界

t=#{i:aᵢ=1}。A=Σaᵢ ≥ t·1+2(m−t)=2m−t ⟹ **t ≥ 2m−A**。
由 A≤2m−1 [继承] ⟹ **t≥1**（与 a₁=1 自洽）。
进一步：A 越大 t 的下界越弱；当 A 取其下界 ⌊m log₂3⌋+1 时 t≥2m−⌊m log₂3⌋−1≈0.415m
（但这是条件式，非无条件——必须写清 A 的取值）。

### L12 [本轮新推] 3-adic 同余不产生独立矛盾（解释为何 3-adic 腿单独无法闭合）

L1 模 3 化约得 n₁≡(−1)^{a_m} (mod 3)，正是决定律在 i=1 的断言（见 L1 附注）。
即：3-adic 同余在 mod 3 层与递推**自动一致**；在 mod 3^m 层它只是 BS 方程在 3-adic 方向的等价重述，
不携带新约束。真正的约束全部来自 2-adic 精确条件 E3。
（与[继承]「素因子覆盖骨架与环方程同义、不产生独立约束」同构。）

### L13 [本轮新推] 候选向量计数

固定 (m,A)，aᵢ≥1、Σaᵢ=A 的组合数为 C(A−1,m−1)。
对所有可允许 A∈[⌊m log₂3⌋+1, 2m−1] 求和 ≤ Σ_{A=m}^{2m−1}C(A−1,m−1)=C(2m−1,m) ~ 4^m/√(πm)
（曲棍球恒等式）。数量级 4^m。

## 2. 主结论（本轮最强可证）

**Collatz 猜想等价于：不存在 m≥2 与正整数 (a₁,…,a_m) 同时满足 L10 的 (E1)(E2)(E3)。**
（m=1 仅平凡环：n₁(2^A−3)=1 ⟹ 2^A=4、n₁=1。）

本轮沿该等价独立推出、且不需任何外部文献的硬事实：

1. **显式双边界**（L3,L4）：对任意正环
   3^{m−1}/(2^A−3^m) ≤ n₁ < 3^m·2^{A−3}，且 N 满足 3^{m−1}≤N<3^m·2^{A−2}/2。
2. **双同余**（L1,L6）：n₁ ≡ N·2^{−A} (mod 3^m) 且 n₁ ≡ N·(2^A−3^m)^{−1} (mod 2^A)；
   CRT 后 n₁ 在模 3^m·2^A 下被奇偶向量唯一确定。
3. **刚性**（L5,L5′）：2^A>(8/7)3^m 时 n₁<3^m，n₁ 被向量**精确**决定；
   对每个 m 非刚性 A 至多一个（δ∈(0,0.192645]）。
4. **局部联合约束**（L7,L8,L9）：mod 3·2^{aᵢ+1} 逐位锁定 nᵢ，mod12 表给出 (a_{i−1},aᵢ) 迁移的完整必要刻画。
5. **计数**（L13）：候选取值 ~4^m。

**这些事实不构成矛盾**——见卡点。

## 3. 卡点（精确技术点）

**卡点1：需要 2^A−3^m 的非常规下界（线性对数型）。**
L4 上界 n₁<3^m·2^{A−3} 用了最弱下界 2^A−3^m≥1。要把它变成矛盾或强排除，需要
2^A−3^m = 3^m(2^δ−1) 的实下界，即 δ=A−m·log₂3 的丢番图下界。这是 Baker 线性对数型范畴
[待验证：精确常数与归属]。已知结果只给出「n₁ 有有效上界 ⟹ 环数有限且可搜索」，不排除存在性。

**卡点2：m≤10^6 覆盖不可行。**
候选向量 ~4^m（L13），m=10^6 时 4^{10^6} 无计算可行性；而 n₁-搜索只排除 min≤X 的环，
m 不由 n₁ 有界（L?：环内 m 个互异奇数落在 [n₁, 2^{m−1}n₁]，只给 n₁ ≳ m/2^{m−1}，无用）。
把「长度 ≤m₀」换成「最小元 ≤X」需要 Baker 型下界（卡点1）。

**卡点3：E3 的合模 2^{A+m}~2^{2.585m} 随 m 无界，有限模 3·2^k 无法闭合动力学。**
L9 的模随 aᵢ 增长，max aᵢ 可达 2m−1（无界），故不存在与 m 无关的有限模使残差链 Markov 化。

## 4. 自检（不等号方向逐行核对）

1. 2^A−3^m>0：N>0,n₁>0 ⟹ 差>0 ✓（方向「差正」，非负）。
2. N≥3^{m−1}：i=1 项 3^{m−1}·2⁰=3^{m−1}，余项>0 累加，≥ 方向正确 ✓。
3. N≤2^{A−a_m}(3^m−1)/2：s_{i−1}≤s_{m−1}（递增）⟹ 2^{s_{i−1}}≤2^{s_{m−1}}，每项放大，Σ3^{m−i}=(3^m−1)/2 ✓。
4. a_m≥2 ⟹ 2^{A−a_m}≤2^{A−2}：指数小则幂小，≤ 方向正确 ✓。
5. 3^m−1<3^m：严格 <，用于 N<3^m·2^{A−2}/2 ✓。
6. n₁=N/(2^A−3^m)≤N：用到 2^A−3^m≥1（正整数），方向 ≤ ✓。
7. n₁<3^m·2^{A−3}：由 5,6 复合 ✓。
8. n₁<3^m 的充分条件 2^A>(8/7)3^m：由 n₁≤2^{A−a_m}(3^m−1)/(2(2^A−3^m)) 放大，
   需 2^{A−a_m}≤2(2^A−3^m) ⟸ 3^m≤2^A(1−2^{−a_m−1}) ⟸ 3^m≤(7/8)2^A，方向逐级正确 ✓。
9. L1 无负号：n₁2^A≡N (mod 3^m) ⟹ n₁≡N·2^{−A}，平凡环验证 ✓；负号版本被平凡环否定 ✗。
10. 2^A−3^m 为奇：偶−奇=奇 ✓；v₂=0 ✓。
11. n₁≡N(2^A−3^m)^{−1} mod 2^A：单位可逆 ✓。
12. L7 双向：nᵢ≡1⟺aᵢ≥2、nᵢ≡3⟺aᵢ=1，用 3^{−1}≡3 mod4 验证 ✓。
13. mod12 表四类：1,7,5,11 各自 (mod3,mod4)=(1,1),(1,3),(2,1),(2,3) ✓。
14. t≥2m−A：A≥t+2(m−t)（非 1 的指数≥2），移项 t≥2m−A，方向 ✓；A≤2m−1 ⟹ t≥1 ✓。
15. L5′ 区间宽：log₂(8/7)=0.192645<1 ⟹ 至多一个整数 A ✓。
16. 平凡环贯穿 L1–L6 校验全部通过 ✓。
