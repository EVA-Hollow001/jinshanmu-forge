# 我用 LLM 把 Collatz 猜想逼进了死角

### ——一次诚实的 AI 辅助数学研究实录

> 结论先行：我们没有证明 Collatz 猜想。我们做的事情更有价值——**用 LLM + 计算验证器，系统性穷尽了一条研究路线的所有初等进攻，把 14 条思路逐一验证、杀死、记录卡点，然后诚实地在墙前收山。** 这份"死路地图"，比一份编造的证明值钱一百倍。

---

## 一、为什么碰 Collatz

Collatz 猜想（3n+1 问题）：任意正整数，偶数除以 2，奇数乘 3 加 1，最终都会回到 1。1937 年提出至今，陶哲轩也只证明了"几乎所有数"的弱化版本，完整证明仍是开放问题。

选择它的原因很实际：

- **验证完全客观**：任何结论都能用几十行代码验证，不存在"看起来对但没法查"
- **文献下界明确**：Simons–de Weger 已把非平凡循环的周期下界推到 10¹⁰，我们有清晰的目标坐标
- **它能逼出方法论**：一个 80 年没人解开的题，是最诚实的压力测试——LLM 到底能不能做数学？

## 二、核心原则：LLM 不是证明机，是假设生成器

大多数"AI 证明 Collatz"的尝试是让 LLM 直接输出一个证明——然后得到一个"看起来严谨、一验就裂"的文本。我们一开始就定了不同的原则：

| 角色 | 谁 | 干什么 |
|---|---|---|
| 假设生成器 | LLM | 生成进攻路线、候选引理、脚本设计 |
| 验证器 | Python/numba/独立脚本 | 对每一个结论做不可贿赂的检验 |
| 拆台者 | 独立模型（grok 等） | 攻击主攻手的论证，找反例 |
| 裁判 | 人 | 决定方向、判断何时收山 |

**关键：验证器和生成器物理隔离。** 同一个模型自我检查永远不够——它检查的也是同一个分布。必须让"生成"和"判定"分离，生成者才能被真正打脸。

## 三、三轮攻坚打下来：14 条死路

整个攻坚分三个轮次、多条路线（routeA/routeB）、多个版本（v1–v5）、多个模块（s1/s2/s3）：

### 正面战果（独立于文献的数值排除）

- **完全排除**：m=2,3,4,7 无非平凡正环 → 非平凡循环必须 m≥5
- **周期排除**：周期 ≤10⁵、最小元 ≤7.22×10⁹ 无非平凡环（R1 最小元扫描 + 覆盖论证）
- **证书**：m=5..10⁵ 共 99,996 个 m 的 B 界证书全部通过（S1）
- **小 D 清层**：D≤10⁹ 层 162 对、8.28×10⁸ 个向量 0 非平凡（R3）
- **扫描墙**：B(m,A₀)=⌊1/(3(2^{d₀/m}−1))⌋ 已推到 m=10⁵；下一层 190537 需 3 天，再上 10⁷ 需 2 年

### 死路地图（每条都标了精确卡点）

| 死路 | 卡在哪 |
|---|---|
| 2-adic 单独证 Collatz | 扩张无紧不变测度 |
| 素因子覆盖→独立矛盾 | 覆盖与环方程乘积恒等式同义 |
| A 唯一化 | (6,10) 反例：d=0.490>0.263 仍在窗 |
| Baker/线性对数单独排除 | 压最小元<5 需指数级 f |
| 窗内夹逼直接排除 | m=5..200 共 1870 对，I=∅ 为 0，零杀伤 |
| 组合筛 | ΣC(A−1,m−1)≈10⁴⁹¹⁶³，天文爆炸 |
| … | 共 14 条 |

**最有价值的一个教训**：窗内夹逼（R2a 方向）看起来极其诱人——"如果区间为空就能排除该层"——但合法方向 D≤N_max/5 在窗内自动成立，零排除力；而非法方向 D≤N_min/5 会误杀 1818/1870 层，包括真实的 (6,10) 反例。**一个方向用错的"漂亮论证"，比十个笨办法更危险。**

## 四、最重要的洞见：LLM 为什么"殊途同归"

我们曾寄希望于 LLM 能"找一条文献没走过的路"。结果它走的路和文献（Simons–de Weger 等）惊人一致。原因值得每一个 AI 数学探索者记住：

1. **训练数据的吸引盆**：LLM 的"自由探索"是在训练分布的高概率区抽样。语料里关于 Collatz"看起来可行"的路径，正是文献走过的路径——它"重新发明"主流方法，和它"重新发明"牛顿法是一个道理。
2. **数学结构本身很窄**：要排除循环就必须处理环方程，2^A≈3^m 就引出连分数。这不是 LLM 的局限，是数学对象的真实结构——**任何人拿现有工具箱都会撞同一面墙。**
3. **LLM 缺"被迫转向"的机制**：数学家被验证器打脸后会换方向；LLM 的自我检查是同一个模型，无法真正"杀死"自己的假设。**这就是为什么必须外接一个不可贿赂的验证器。**

## 五、预测-验证-对账管线：让 LLM 被现实修正

作为方法论收尾，我们实现了一条"预测→验证→对账→校准"管线（[collatz_pipeline.py](collatz_pipeline.py)）：

1. 生成 10 个跨量级 Collatz 区间
2. **LLM 先写预测**（赌最大停滞时间/平均停滞/置信度）——纯直觉，不计算
3. **numba 验证器跑真实值**
4. **对账**：计算预测 vs 真实的偏差，记录"打脸"
5. **校准**：把偏差回灌，LLM 第二轮重预测

核心机制是**预测-验证对账（Prediction-Verification Reconciliation）**：强制 LLM 先表态、再被打脸、然后修正。这比"跑一下看结果"的被动验证有质的不同——**被自己的预测打脸，是认知上的"本体论意外"；看一眼结果，只是读取。**

## 六、给 AI 数学探索者的三条建议

1. **永远外接验证器，且让它不可贿赂**。Lean/Z3/numba 都可以——关键是生成和判定物理分离。LLM 永远不能"说服"验证器。
2. **写死路地图，不要只写结论**。每一轮记录"什么思路死了、卡在哪个技术点、为什么"。这份地图比任何幸存者偏差的总结都有价值——你的攻坚结束后，后人能直接跳过你踩过的 14 个坑。
3. **止损要前置**。设定"多少轮、多少预算、什么信号就收山"，然后让信号自动触发。我们最值钱的文件是"山穷水尽报告"——它不是失败记录，它是**把搜索空间排除干净后留下的地图**。

## 七、关于"AI 能不能做数学"

我们的答案：**能，但以你没想到的方式。**

- LLM 不能证明 Collatz——任何声称证明了的大概率是幻觉
- 但 LLM + 验证器 + 死路地图 = 一个能系统性穷尽研究路线、产出可复用方法论、并且**诚实地知道自己撞了墙**的科研组合
- 这比"让 LLM 编一个证明"有用得多。前者是科研，后者是幻觉

**这份攻坚最诚实的自我评估：证明 Collatz 的主观概率 0.5–2%。但把一条路走到底、把墙摸清楚、把地图留下来——这件事的概率是 100%。**
