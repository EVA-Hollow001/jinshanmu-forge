# 给 AI 数学证明装一个测谎仪：负侧鉴别器

用 Collatz 猜想做例子。这题正侧（正整数）猜没有非平凡循环，负侧（负整数）却真的有：−5 → −14 → −7 → −20 → −10 → −5 是一个环，−17 也有一圈，−1 更是直接不动。

这个事实免费送了一个审稿工具：

> 任何声称「排除正循环」的论证，把每一步在负侧原样重跑。某一步如果在负侧也成立，这一步就杀不了正循环。否则它连带证伪真实存在的 −5 环。

负侧循环就是测谎仪。AI 写证明时最擅长产出「看起来都对」的步骤，这台仪器能把其中没有判别力的部分直接筛出来，不用读懂它每一步。

## 实测：20 条断言死 11 条

第一轮攻坚，四条互盲铺路路线交上来 20 条关键断言。拆台手（Grok）把每条在 −5 环和 −17 环上重跑：

| 断言 | 在负侧 | 裁决 |
|---|---|---|
| mod 3 决定律 nᵢ≡(−1)^{a_{i−1}} | −17 环七项全成立 | 杀。无判别力 |
| gcd(nᵢ,n_{i+k}) 整除 N_k | 符号无关，全成立 | 杀 |
| N 夹逼 3^m−2^m ≤ N ≤ 2^{A−m}(3^m−2^m) | 同样成立 | 杀 |
| n₁≡N·D⁻¹ (mod 2^A) | B–S 方程改写，成立 | 杀 |
| 正循环 ⟺ A/m > log₂3 | (4,7) 反例：A/m>log₂3 但 m=4 无环 | 杀，⟺ 过强 |
| n₁ ≤ 1/(2^{A/m}−3) | 方向反转，−5 环实测违反 | 活。真带基因 |

结论很干净：排除正循环的证明，至少要有一步在负侧失效。少这一步，整条链都是装饰。

## 但测谎仪自己也会误报

第二轮攻击时发现了过杀案例。C3/C4 那组排除（正侧窗口 (log₂3, log₂3+0.096] 内 m=2,4,7 没有整数 A；m=3 时 N=25 不落在穷举表里）用的全是符号无关的算术，只靠一个正侧专属的参数盒子杀掉了真环。机械套过滤器会把这两条真排除也判成雷区。

所以过滤器要加例外条款：**「负侧也成立的恒等式」+「正侧专属的参数域」不算雷区**。判别力来自参数域的方向性，不来自恒等式本身。

## 两个副产品比过滤器值钱

第一，侧向反转是唯一硬基因。正循环要求 A/m 从**上侧**逼近 log₂3，负循环从下侧。这是两侧唯一的不等式方向反转，后来直接长出了「A 唯一化定理」：真循环时每 m 的 A 被唯一强制成 ⌈m·log₂3⌉，两参数问题塌缩成一参数。

第二，小值占用学。|2^A−3^m|=1 只有两个整数解：2²−3=1 和 3²−2³=1。前者被正侧平凡环 (1,2) 占用，后者被负侧 −5 环 (2,3) 占用。这解释了为什么正侧只有平凡环而负侧有非平凡环。正确证明的形状应该是「小值已穷尽」，而不是「覆盖矛盾」。

## 这方法哪里都能用

只要你要证明「不存在 X」，而某个变体里 X 真实存在，就把证明的每一步丢进那个变体跑一遍。正特征域证明在负特征域重跑，算法终止性证明在已知发散的参数区重跑，群性质证明在已知反例群上重跑。镜像对象就是现成的对抗样本。
